홈 화면에 추가해서 쓰세요

Safari 아래쪽 공유 버튼(□↑) → 홈 화면에 추가를 누르면 앱처럼 설치됩니다. 설치한 앱으로 열어야 입력 내용이 오래 보관되고, 인터넷 없이도 열립니다.

설정

'건물 층'처럼 앞에 건물 이름을 붙이면 건물 버튼을 눌렀을 때 그 아래에 층 버튼으로 나옵니다. 목록에 없는 곳은 점검 화면의 '직접 입력' 칸에 쓰면 됩니다.

기관에서 받은 설정 파일(위치 목록 등)을 불러오면 한 번에 채워집니다. 불러온 뒤 '설정 저장'을 누르세요.

사진과 입력 내용은 이 휴대폰 안에만 저장되며 외부(AI 포함)로 전송되지 않습니다. 만든 hwpx는 휴대폰에 파일로 저장되고, PC로는 직접 옮기면 됩니다(USB 케이블, 기관 메일 등).

이 브라우저에서는 입력 내용을 저장할 수 없습니다. 창을 닫거나 새로고침하면 사진·내용이 사라지니, 점검을 마치면 바로 hwpx 만들어 저장을 누르세요. (홈 화면에 추가한 앱으로 열면 저장됩니다)

점검 1건에 사진 1~3장이 들어갑니다. 사진대지 1쪽에는 2건씩 배치됩니다.

파일이 준비됐습니다

아래 버튼 → 공유 창에서 '파일에 저장'을 고르세요. (사진은 '이미지 저장'도 됩니다)
